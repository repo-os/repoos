# Architecture Decision Records

ADRs record a decision that shaped RepoOS, why it was made, and what it rules
out. They are immutable once accepted — if a decision changes, it gets a new
ADR, not an edit. (Process: the "Principles" section of the [Vision](/vision).)

| ADR | Decision | Status | Date |
| --- | --- | --- | --- |
| [0001](/adr/0001-repo-native-tasks) | Tasks are repo-native markdown files | accepted | 2026-05-29 |
| [0002](/adr/0002-status-as-frontmatter) | Status is a frontmatter field, not a folder | accepted | 2026-05-29 |
| [0003](/adr/0003-self-hosting) | Self-host RepoOS on RepoOS | accepted | 2026-05-29 |
| [0004](/adr/0004-plugin-architecture) | Core stays minimal; project-specific integrations are plugins | accepted | 2026-06-03 |
| [0005](/adr/0005-agents-use-repoos-apis-for-privileged-operations) | Agents use RepoOS APIs for privileged operations | accepted | 2026-08-11 |
