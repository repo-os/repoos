RepoOS is installed on this machine as the `repoos` command. Figure out how it works from the tool itself and its documentation, then use it to plan and build the app below. Work in the current directory.

{{IDEAS}}

Keep authentication turned off in RepoOS's settings; don't enable login for this project.

Other people are building different projects on this machine at the same time. Give your project its own distinctive name (for the app and for the RepoOS repo), and when you start `repoos serve`, let it pick its own port automatically; don't pass `--port` or pin one. For the app you're building, pick a random port between 3000 and 3999 for it to listen on (not a common default like 3000), and use that same port every time you run it.

Keep going until the app works and you're happy with it. If you get stuck, find a way forward on your own; nobody is available to answer questions.
