## Problem
When a review passes and a task is "good to go," the "Move to done" button looks like any other button. It's easy for the human to miss that action is needed.

## Fix
Visually call out the Move to done button once review passes clean (flash/pulse/highlight), so it's obvious the task is ready and waiting on a human click.
